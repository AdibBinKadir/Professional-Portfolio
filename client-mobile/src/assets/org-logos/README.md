Place organization logos here for the mobile client.

Recommendations:
- Use PNG or SVG files with transparent backgrounds.
- Name files using lowercase hyphenated slugs, e.g. `tmss.png`.

Usage (mobile):
1. Import in component: `import tmssLogo from './assets/org-logos/tmss.png'`
2. Set the activity `img` field: `{ id:1, ..., img: tmssLogo }`

This file documents how to upload and reference logos in mobile components.
