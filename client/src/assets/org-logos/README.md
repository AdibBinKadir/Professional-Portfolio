Place organization logos here. Recommended:

- Use square PNG or SVG files (e.g. `tmss.png`, `astros.png`) sized ~256px and let CSS scale down.
- Prefer transparent PNG or vector SVG for best results.
- Naming convention: `org-slug.png` (lowercase, hyphens). Example: `tmss.png`

Usage in components:
1. Import the file in the component, e.g. `import tmssLogo from './assets/org-logos/tmss.png'`
2. Set the activity `img` field to the imported symbol: `{ id:1, ..., img: tmssLogo }`

This README is just a helper for uploading and usage.
